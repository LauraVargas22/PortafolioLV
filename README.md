Este proyecto contiene el portafolio personal de Laura Vargas como desarrolladora de software, con secciones para perfil profesional, estudios, experiencia, tecnologias, proyectos y contacto.

Sitio publicado:
`https://lauravargasportafolio.netlify.app/`

## Contenido

- Inicio
- About Me
- Skills
- Aspirations
- Projects
- Contact

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Vite

## Instalacion y Uso

1. Clonar el repositorio.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev` para desarrollo.
4. Ejecutar `npm run build` para produccion.
